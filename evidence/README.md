# evidence/

Raw, unedited output captured by `validate/Get-LabEvidence.ps1`.

Each file is the stdout of one command with a capture timestamp header. Nothing
here is rendered, summarised or hand-edited — if a figure quoted in the project
README does not appear in one of these files, the figure is wrong.

`initial-credentials.csv` and `fault-state.json` are gitignored. Generated
passwords do not belong in a repository.
